À propos de cet espace

Motif Planner centralise le calendrier, les tâches et la coordination de l'équipe. Cette version fonctionne en mode local dans ce navigateur. La synchronisation multi-appareils nécessite le serveur Python démarré et configuré.

Canal général

Appels audio / vidéo

WebRTC est intégré au navigateur. Les appels entre appareils nécessitent une signalisation accessible publiquement et, selon les réseaux, un relais TURN.

Le backend Python doit être hébergé sur une machine accessible depuis Internet pour établir des appels entre membres. GitHub Pages ne peut pas exécuter le serveur.

Aucun appel ne sera lancé dans cette version statique.
